## 🌟 How to Join the Contributor Ladder

1. Pick an open issue tagged [`wave-10`](https://github.com/viappToken/viapp/issues) or [`good-first-issue`](https://github.com/viappToken/viapp/issues) in our issue tracker.
2. Read the [Contribution Guidelines](./CONTRIBUTING.md) and run `npm run community:check`.
3. Submit a pull request referencing a single issue (`Closes #<issue-number>`) with passing automated tests.
4. Once your PR is reviewed and merged, add your GitHub handle and contribution summary to this ledger.

ViApp's core smart contract is `viapp-gift-vault`, compiled to `wasm32v1-none` and deployed on the Stellar Testnet. It holds tokenized stock Stellar Asset Contracts (SACs) locked in escrow until the recipient's ephemeral link key claims them through ViApp's gasless relayer, or the sender retrieves them after expiration.

## Exported Contract Functions (`packages/contracts/stellar/src/lib.rs`)

### Constructor & Public Entrypoints

| Function | What it does | Error Conditions |
|---|---|---|
| `__constructor(admin, relayer, initial_tokens)` | Atomic CAP-0058 constructor initializing the vault owner, authorized relayer, and listed SAC tokens at deployment. | `AlreadyInitialized`, `TooManyTokens` (> 32). |
| `create_gift(sender, token, amount, claim_key, expiry, sealed_note, key_proof)` | Requires `sender.require_auth()`. Verifies Ed25519 `key_proof`, pulls `amount` of `token` into escrow, increments `Liabilities(token)`, and extends persistent TTL (95 days). | `Paused`, `TokenNotListed`, `ZeroAmount`, `ClaimKeyAlreadyUsed`, `ExpiryOutOfRange` (< 1 hr or > 90 days), `NoteTooLong` (> 512 B). |
| `claim(gift_id, recipient, signature)` | Requires `relayer.require_auth()`. Verifies Ed25519 `signature` from `gift.claim_key` over `("viapp:claim:", network_id, contract_id, gift_id, recipient)` and transfers tokens to `recipient`. | `Paused`, `GiftNotOpen`, `GiftExpired`, `BadRecipient`. |
| `refund(gift_id)` | Unpausable after `gift.expiry`. Marks gift `Refunded`, decrements `Liabilities(token)`, and returns principal to `gift.sender`. | `GiftNotOpen`, `GiftNotExpired`. |
| `get_gift(gift_id)` | Returns `Option<Gift>` (`token`, `sender`, `claim_key`, `amount`, `expiry`, `state`, `sealed_note`). | Never panics; returns `None` for unknown IDs. |
| `next_gift_id()` | Returns the `u64` ID that the next created gift will receive. | Never panics. |
| `listed_tokens()` / `is_listed(token)` | Returns the `Vec<Address>` of listed SAC tokens or checks a single token. | Never panics. |
| `liabilities(token)` | Returns the total `i128` escrowed liability across open gifts for `token`. | Never panics. |

### Protocol Admin Functions

| Function | What it does |
|---|---|
| `set_token_listed(token, listed)` | Requires `admin.require_auth()`. Dynamically adds or removes a SAC token from the allowlist and emits `TokenListed`. |
| `set_relayer(new_relayer)` | Requires `admin.require_auth()`. Updates the authorized gasless relayer address and emits `RelayerUpdated`. |
| `rescue_surplus(token, to)` | Requires `admin.require_auth()`. Rescues tokens sent to the contract strictly above `liabilities(token)` and emits `SurplusRescued`. |
| `pause()` and `unpause()` | Requires `admin.require_auth()`. Pauses or resumes `create_gift` and `claim` (`refund` remains unpausable). |
| `extend_ttl()` | Extends instance and persistent token registry TTLs on Stellar ledgers. |

## Live Verification via Stellar CLI

Inspect the live Testnet contract directly using the official `stellar` CLI:

```bash
# 1. Query the next gift ID
stellar contract invoke \
  --id CDG2MIJEGLAIS37FXNF3KSFIQYL4VN5AUVLRLXK47SHQTHVVILPKCBD4 \
  --source-account GAZWESWQPZOIH2EH3IL37THBLKGLAC5FCHTLMWAXJGLKJPT4NRRIHN6B \
  --network testnet \
  --send=no \
  -- next_gift_id

# 2. Query all 11 listed SAC token contract addresses
stellar contract invoke \
  --id CDG2MIJEGLAIS37FXNF3KSFIQYL4VN5AUVLRLXK47SHQTHVVILPKCBD4 \
  --source-account GAZWESWQPZOIH2EH3IL37THBLKGLAC5FCHTLMWAXJGLKJPT4NRRIHN6B \

  -- listed_tokens
```
